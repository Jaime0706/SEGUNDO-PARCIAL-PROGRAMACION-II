## Descripción
Aplicación de consola en Java para la gestión de un estacionamiento comercial aplicando POO (abstracción, herencia, polimorfismo, sobrescritura, encapsulamiento), colecciones (`ArrayList`, `HashSet`, `HashMap`), validaciones y manejo de excepciones (`try-catch-finally`). Incluye script de persistencia en PostgreSQL con restricciones de integridad.

## Estructura
- `src/`: Código fuente de la aplicación Java.
- `database/`: Script SQL para la base de datos `parcial2_estacionamiento`.
- `evidencias/`: Documentación visual del funcionamiento.
